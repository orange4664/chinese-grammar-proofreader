# chinese-grammar-proofreader

一个只查中文病句的 Skill。

灵感来自于改了半天突然回忆起来是高中语病题，人工越改越发现很难改，但是然后越改越觉得熟悉，and 就这样了。

**可以极大地提升可读性。** 能不能降低 AI 率不清楚。

## 它能抓到什么

下面的例子来自 `references/casebook.md`。共同点是第一眼都不觉得有问题。

**一个动词带两个宾语，只有一个搭得上**

> 减少实验时间和误差

"减少误差"没问题，"减少时间"不对。拆开：缩短实验时间并减小实验误差。

同类的还有"提高设备稳定性和使用范围"——稳定性可以提高，使用范围只能扩大。

**主语被介词吃掉了**

> 通过连续三天的复测，使我们排除了仪器故障

"通过……使……"这个结构一旦两头都是介词短语，主语就没了。去掉"使"就行：通过连续三天的复测，我们排除了仪器故障。

但也不能见到就判错。"学校通过延长开放时间，使更多学生能够进入实验室"是成立的，因为"学校"是明确的施事。Skill 里把这类结构列为只触发复查、不自动判错。

**写着写着换了主语**

> 这项方案经过专家反复论证，项目组最终决定采用第二版

前半句以"方案"起头，后半句主语变成"项目组"，前面的结构就悬空了。改成：经过专家反复论证，项目组最终决定采用这项方案的第二版。

**代词指向两个人都说得通**

> 小周告诉小吴，他的申请已经通过了

"他"是小周还是小吴，两种读法都自然。这种只能按原意改，不能替作者猜——所以 Skill 会给两个分支让你选。

**前面两面，后面一面**

> 是否按时复习，是取得好成绩的重要条件

前半句说的是"是否"，后半句只写了"取得好成绩"这一面。补上：是能否取得好成绩的重要条件。

这类在中文里叫"两面对一面"，是母语者也经常写错的一类，通用模型基本不会主动去查。

**因果推不出来**

> 他今天没有发言，因此他一定不同意这个方案

没发言推不出不同意。这是句内逻辑问题，不是事实核查。

**动作顺序反了**

> 我们发现并排查了故障原因

得先排查才能发现。

## 覆盖范围

六大类是语序不当、搭配不当、成分残缺或赘余、结构混乱、表意不明、不合逻辑。

在这之上还强制单独扫一遍这些：句式杂糅、指代不明、歧义、关联词错误、两面对一面、否定失当、数量与范围、标点。

两面对一面和否定失当单列出来是有原因的。它们是中文特有的坑，而且英文里没有对应物，模型不会主动去查。

## 它刻意不做的事

不因为审美不同改句子。不为了显得严格硬挑错。不把文学性的反复、汉语正常的省略、口语表达按考试作文的标准判错。

看到"通过……使……""由于……因此……""是否/能否"这些高危结构，先抽主干再说，不自动报警。很多病句检查器就是靠模式匹配的，看到高危结构就亮红灯，误报多到没法用。

## 用法

```
检查这句话有没有语病
按高考语文标准检查下面这段
只找病句，不要润色
找出所有病句，标类型并做最小修改
仔细检查两面对一面、否定和关联词
连标点一起检查
```
