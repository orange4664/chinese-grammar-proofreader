# Research basis / 参考依据

本 Skill 为“纯病句”版本。构建时参考了公开的现代汉语、语文考试和出版编校资料，
并将例句重新编写为训练例，避免把具体网页中的原句机械复制为模板。

## 1. 病句六大类型

普通高校招生语文考试大纲及多类语文考试大纲长期采用六大类型：

- 语序不当
- 搭配不当
- 成分残缺或赘余
- 结构混乱
- 表意不明
- 不合逻辑

参考：
- 中国高等教育学生信息网（阳光高考）历年语文考试大纲
  https://gaokao.chsi.com.cn/
- 北京电子科技职业学院 2026 年招生考试大纲
  https://www.bitc.edu.cn/

## 2. 六大病句及细分实例

北京师范大学出版科学研究院的编辑校对资料对六大类病句作了系统拆分，
包括定语/状语语序、关联词位置、主谓/动宾/主宾搭配、成分残缺、句式杂糅、
指代不明、歧义、自相矛盾、范围不清、强加因果、否定失当等。

参考：
https://pub.bnu.edu.cn/jzyg1/41416.html

## 3. 防止过度判错

北师大出版科学研究院关于语法差错判定的讨论强调：
汉语语法具有语境性和灵活性，省略、词性活用等现象不能仅靠机械规则判错；
编校中也应避免过度修改。

参考：
https://pub.bnu.edu.cn/jzyg1/129013.html

另有专题讨论指出，“通过……使……”是否构成病句必须分析句中主体，
不能只凭表面格式一刀切。

参考：
https://pub.bnu.edu.cn/jzyg1/07a7508a5e7f42dfa1325d6f7a2dc0d0.html

## 4. 逻辑错误专项

北师大出版科学研究院及高校学报编校资料对以下问题有专门总结：

- 量项不当
- 两面对一面 / 照应不周
- 否定失当
- 关联逻辑错误
- 条件关系错误
- 判断歧义

参考：
https://pub.bnu.edu.cn/jzyg1/10f22e14d14444298d276c587b302f63.html
https://jed.imust.edu.cn/info/1003/2242.htm

## 5. “一词搭配多个并列项”专项

公开语言文字规范资料强调，长句中常出现一个谓语只能与部分并列宾语搭配的隐蔽错误，
因此本 Skill 强制进行“逐项拆开配对”的横向搭配测试。

参考：
https://yywzw.jlbtc.edu.cn/content.jsp?archive=0&urltype=news.NewsContentUrl&wbnewsid=1713&wbtreeid=1027

## 6. 成分重复 / 赘余

北师大出版科学研究院的编校案例总结了“大约……左右”“主要以……为主”
“宜……为宜”等常见表意重复，同时提醒文学性反复不能机械删除。

参考：
https://pub.bnu.edu.cn/jzyg1/128152.html

## 使用原则

这些来源用于建立诊断框架，不意味着任何单一网页拥有“唯一正确”的汉语语法标准。
遇到边界案例时，Skill 应优先：

1. 判断现实语义是否明确；
2. 判断结构是否真正造成误解或冲突；
3. 区分考试规范、出版规范、口语和文学语境；
4. 在证据不足时标记“依赖语境”，而不是强判病句。
